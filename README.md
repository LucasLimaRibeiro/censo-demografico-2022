# Censo Demográfico 2022: um retrato da população brasileira

## Apresentação do projeto

Este projeto tem como objetivo desenvolver uma análise dos dados do **Censo Demográfico 2022**, realizado pelo Instituto Brasileiro de Geografia e Estatística (IBGE).

A proposta é explorar informações sobre a população brasileira, buscando compreender suas características demográficas e sociais por meio da manipulação, organização, análise estatística e visualização de dados.

O trabalho será desenvolvido utilizando Python e suas principais bibliotecas de análise de dados, seguindo boas práticas de engenharia de dados, documentação e reprodutibilidade.

## Objetivos

- Explorar dados oficiais do Censo Demográfico 2022.
- Realizar a leitura, limpeza e transformação das bases de dados.
- Identificar padrões e características da população brasileira.
- Desenvolver indicadores estatísticos.
- Criar visualizações para facilitar a interpretação dos resultados.
- Disponibilizar os dados e procedimentos utilizados de forma organizada e reproduzível.

## Fonte dos dados

**Instituto Brasileiro de Geografia e Estatística (IBGE)**

Censo Demográfico 2022.

Fonte oficial: https://www.ibge.gov.br/estatisticas/sociais/trabalho/22827-censo-demografico-2022.html

A primeira base selecionada para o desenvolvimento da análise corresponde à tabela 9514, relacionada à população residente por grupos de idade, com informações para o Brasil, Grandes Regiões e Unidades da Federação.

Outras tabelas oficiais poderão ser incorporadas ao projeto conforme a necessidade da análise.

## Metodologia

O desenvolvimento será dividido em quatro etapas principais:

1. **Aquisição e organização:** obtenção das bases oficiais disponibilizadas pelo IBGE.
2. **Engenharia de dados:** leitura, limpeza, tratamento e transformação dos dados utilizando Python.
3. **Análise exploratória:** cálculo de indicadores, estatísticas descritivas e identificação de padrões.
4. **Comunicação dos resultados:** criação de gráficos e desenvolvimento de um artigo acadêmico em HTML.
